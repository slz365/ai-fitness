# AI 健身教练 🏋️

一个基于 DeepSeek 大模型的个人 AI 健身教练 App。录入身体数据与训练动作，AI 为你生成个性化训练计划、记录每日饮食与运动、评估训练效果，并给出每日改进建议。

## ✨ 功能特性

- **个性化引导**：录入身高、体重、健身目标（增肌/减脂/塑形/力量提升）以及日常训练动作和重量
- **AI 生成计划**：基于你的身体数据与动作库，AI 生成针对性训练计划，支持对计划提建议实时调整
- **每日记录**：饮食按早/中/晚/加餐分餐次记录，支持标记放纵餐；运动记录每天训练内容
- **AI 每日评估**：每天记录后，AI 自动判断饮食/运动是否达标，并给出明日建议
- **数据可视化**：体重曲线、力量进步曲线（按动作分组）、训练打卡日历
- **本地持久化**：档案、记录、计划、评估结果均保存在浏览器本地，关闭不丢失

## 🛠 技术栈

- **前端**：原生 HTML + CSS + JavaScript（响应式，适配手机）
- **后端**：Node.js + Express（本地开发）/ Vercel Serverless Functions（部署）
- **AI**：DeepSeek API
- **部署**：Vercel（免费）

## 🚀 快速开始

### 本地开发

```bash
# 1. 安装后端依赖
cd server
npm install

# 2. 配置 API Key（在 server/.env 中填入）
DEEPSEEK_API_KEY=sk-你的密钥

# 3. 启动后端
node server.js

# 4. 浏览器打开
http://localhost:3000
```

### 部署到 Vercel

1. 将代码推送到 GitHub 仓库
2. 在 Vercel 中导入该仓库
3. 设置环境变量 `DEEPSEEK_API_KEY`
4. 部署完成，即可通过 `.vercel.app` 域名访问

## 📝 使用说明

1. 首次打开填写身体数据、目标和训练动作
2. 在「计划」页让 AI 生成训练计划，可随时提建议调整
3. 每天在「记录」页记录饮食和运动
4. 记录后点「AI 评估今天」获取达标判断和建议
5. 在「我的」页查看体重/力量曲线和打卡日历

## ⚠️ 注意

- 数据存储在浏览器本地，清除浏览器数据或更换设备会导致数据丢失
- 如需多设备同步，需接入云端数据库
